Introduction to TACC
================================================

To effectively use TACC's high-performance computing (HPC) clusters, it is important to become familiar with TACC ecosystem. 
In this unit, we will:

* Understand the basic architecture of High-Performance Computing (HPC).
* Create a TACC account and set up multi-factor authentication (MFA).
* Log in to a remote HPC system at TACC.
* Navigate the TACC file systems.
