The Command Line Interface 
============================= 

Most research computing infrastructure, including the HPC clusters and cloud resources at TACC, runs Linux. HPC clusters can be accessed through a command-line interface (CLI), a text-based interface where users type commands to interact directly with a computer. In research computing, the CLI is used to log into remote systems, manage files, and launch computational analyses.

In this section, you will learn to:

* Use the CLI to interact with HPC clusters
* Transfer file from and to the HPC clusters 
* Use a Linux text editor such as Nano or VIM
