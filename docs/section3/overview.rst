Running jobs on HPC Systems
==============================

Now that we learned how to navigate the filesystem and edit text files, we are ready to use the HPC cluster to run our jobs.
In this section, you will learn to:

* Start an interactive session on a compute node
* Submit a batch job to a queue with a SLURM batch job submission file
* Monitor the job progress
* Manage software modules
